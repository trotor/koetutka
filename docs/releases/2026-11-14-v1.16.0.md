## Mitä julkaistiin

- **Suosikit kuukausikalenterina** (mobiili): Suosikit-välilehden Kuukausi-näkymä,
  ruudukko ma–su, suosikit suosikkivärein, päivän napautus listaa sen kokeet,
  värien selite. Logiikka `shared/src/month-grid.ts`. Entinen Kalenteri = Aikajana.
- **iOS-korjaukset**: banneri huomioi turva-alueen (kello peitti otsikon kaikilla
  Dynamic Island -iPhoneilla), kokeen tietojen otsikko ei jää yläpalkin alle.
- **Kauppasivut uusiksi**: `mobile/store/listing.fi.json` (tekstit),
  `make-marketing.py` (otsikoidut kuvat), `push-listing.py` (vienti kauppoihin).
  Play-kuvissa ei UUTTA-merkkiä (Playn ohjeet kieltävät aikasidonnaiset sanat).
  Feature graphic ennallaan.
