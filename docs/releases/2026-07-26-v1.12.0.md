# Julkaisu 1.12.0 — 26.7.2026

Ensimmäinen julkaisu, jossa web, iOS ja Android ovat **samassa versiossa**.
Mobiili hyppäsi 1.7.1 → 1.12.0 kuroakseen kiinni webin, joka oli ajautunut
edelle. Pidä ne jatkossa lukossa toisiinsa.

| | versio | build |
|---|---|---|
| Web | 1.12.0 | — |
| Android | 1.12.0 | `versionCode 12` |
| iOS | 1.12.0 | `CURRENT_PROJECT_VERSION 10` |

## Mitä julkaistiin

- **Neljä uutta kenttää SNJ:n rajapinnasta** JSONiin (`snj_kokeet.py`):
  `state`, `entry_start`, `entry_end`, `entries`. Kaikki optionaalisia, jotta
  vanha sovellusversio sietää uutta dataa ja uusi versio vanhaa.
- **Kokeen tila** merkkinä listakorteissa ja tietonäkymässä: Alustava, Peruttu,
  Osallistujat valittu, Kutsut lähetetty. Tila ohjaa myös `isRegistrationOpen`ia,
  eli "Ilmo auki" ei enää valehtele kokeesta jonka osallistujat on jo valittu.
- **Yksi tilannetietoinen SNJ-linkki per koe** (`shared/src/snj.ts`, `snjLink`):
  ilmoittautuminen kun se on auki, lähtölista kun kutsut on lähetetty, muuten
  koekalenterin etusivu.
- **Ilmoittautuneiden määrä** paikkamäärän vierellä ("15 paikkaa · 22
  ilmoittautunutta").
- **Painettavat yhteystiedot** mobiilin tietonäkymässä (`tel:` / `mailto:`).
- **Android 16 (API-taso 36)** — Google Playn 31.8.2026 vaatimus.

## Mitä opittiin SNJ:n rajapinnasta

Nämä maksoivat kaksi korjauskierrosta ja ovat helppo päätellä väärin uudelleen:

- **`/event/:type/:id` ei ole kokeen ilmoitussivu vaan ilmoittautumislomake.**
  Se palauttaa `410 Ilmoittautuminen ei ole avoinna` kun ilmo ei ole auki, ja
  **renderöityy tyhjänä** kun koe on `tentative`. Julkista per-koe-ilmoitussivua
  ei ole olemassa.
- **Lähtölista syntyy kutsujen lähettämisestä, ei osallistujien valinnasta.**
  Mitattu: `picked` → `/prod/startlist/{id}` 404 (9/9), `invited` → 200 (15/15).
- **`/prod/startlist/{id}` on auki ilman autentikointia**, mutta CORS on rajattu
  `https://koekalenteri.snj.fi`. Sisältää henkilötietoa (nimet, rekisterinumerot,
  mikrosirutunnukset, koiran koko tuloshistoria) — sitä ei peilata meidän
  domainille. Perustelut speksissä, ks. alla.

Suunnitteludokumentit: `docs/superpowers/specs/2026-07-25-koeilmoitus-linkki-ja-tila-design.md`
ja `docs/superpowers/plans/2026-07-25-koeilmoitus-linkki-ja-tila.md`.

## Jäljelle jääneet työt

Kaksi tunnettua asiaa, jotka rajattiin tietoisesti tämän julkaisun ulkopuolelle:

1. **`shared/tests/ics.test.ts` kaatuu `TZ=UTC`:lla** (`DTSTART` off-by-one).
   Tätä julkaisua vanhempi vika. Se on piilossa siksi, että **mikään workflow ei
   aja testejä** — `deploy.yml` vain buildaa sharedin. Testiaskel CI:hin paljastaisi
   tämän ja suojaisi jatkossa.
2. **`shared/src/ics.ts` kirjoittaa `STATUS:CONFIRMED` aina**, joten peruttu koe
   viedään käyttäjän kalenteriin vahvistettuna. Nyt kun `state` on datassa,
   `STATUS:CANCELLED` on käytännössä yhden rivin muutos.

Harkittavaksi: web ei himmennä peruttuja kokeita kuten mobiili tekee, ja
`isCancelled` on viety webin `window.koetutkaShared`-siltaan mutta jää käyttämättä
— joko toteuta himmennys tai poista silta-vienti.
